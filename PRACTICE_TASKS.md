1. Run the project.
2. Call GET /api/trades.
3. Add a POST trade.

5. Add a `status` field to `Trade`.
6. Update sample trade data.
7. Run `mvn test`.
8. Commit your changes.
9. Push your branch.
10. Create a Merge Request / Pull Request.
